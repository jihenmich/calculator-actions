# calculator-actions

# Kalkulator-Projekt mit GitHub Actions

Dieses Projekt enthält eine einfache JavaScript-Kalkulatorfunktion (`add`), die zwei Zahlen addiert. Das Ziel dieses Projekts ist es, die Funktionsweise von GitHub Actions zu demonstrieren, indem bei jedem Push auf den `main`-Branch automatisch Tests ausgeführt werden.

## Funktionen

- Eine Funktion `add(a, b)`, die zwei Zahlen addiert und das Ergebnis zurückgibt.
- Ein automatisierter Test, der sicherstellt, dass die Addition korrekt funktioniert.
